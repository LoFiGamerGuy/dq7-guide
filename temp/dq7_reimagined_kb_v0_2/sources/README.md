# Source cache policy

This directory intentionally contains no mirrored guide pages.

Committed source material should be limited to:

- source registry metadata;
- normalized facts and original summaries;
- short evidence excerpts only when needed to resolve a conflict;
- user-owned in-game screenshots or observations, with platform and patch metadata.

Temporary HTML or screenshots used during ingestion should stay outside version control unless the user owns them or redistribution is clearly permitted. Always retain the canonical URL and a precise locator in the database.
