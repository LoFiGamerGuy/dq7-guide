Phone Setup

Use it while playing

  1. Keep the phone and host on the same trusted Wi-Fi.
  2. For one session, run start-guide-phone.sh. For a background server, run ./manage-steam-deck-guide.sh start.
  3. Open the printed phone address. The background server survives closing its terminal while Desktop Mode remains active.
  4. Use status, stop, or restart with the same manager. Your bookmark survives restarts; use rotate only to revoke it.
  5. Bookmark this page. Use Current to return to your saved checkpoint; Prev/Next only browse.
SteamOS limitationSuspending, rebooting, changing network, or switching SteamOS sessions can stop or disconnect a user process. Check status and restart if needed. No root service or hidden autostart is installed.
Local HTTP is online-to-host onlyNormal LAN phone addresses cannot use the offline service worker. Installation/offline caching requires localhost or a secure HTTPS origin. Never expose this write-enabled guide to public Wi-Fi or the internet.

If the phone disconnects

  1. Keep the launcher terminal open.
  2. Confirm both devices remain on the same Wi-Fi; disable phone VPN or cellular fallback temporarily.
  3. Allow Python through the host firewall on private networks.
  4. Reload this page after reconnecting. Do not repeat a change unless the guide shows it as unsaved.
